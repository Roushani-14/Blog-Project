# Blog Application & REST API

A simple blog application built using **Node.js, Express.js, and REST APIs**.  
The project demonstrates how to build a custom RESTful API and connect it to a frontend application using Axios.

## 🚀 Features

- Create new blog posts
- View all blog posts
- View individual blog posts
- Edit existing blog posts
- Delete blog posts
- RESTful API for managing blog data
- Frontend communicates with the backend API using Axios
- Server-side rendering using EJS
- Uses an in-memory data store for storing posts

## 🛠️ Tech Stack

- **Node.js** – Backend runtime
- **Express.js** – Web framework and API development
- **REST API** – Communication between frontend and backend
- **Axios** – HTTP requests from frontend to API
- **EJS** – Server-side rendering
- **HTML/CSS** – Frontend interface
- **Body-Parser** – Parsing incoming request data
